The Spring Boot backend currently remains at the repository root. Do not place Angular files under the backend `src/` directory.

Expected application structure once the Angular app is scaffolded:

```text
frontend/src/app/core/
frontend/src/app/shared/
frontend/src/app/features/
```

This directory currently contains only the agreed folder boundary and placeholder files. The Angular app has not been scaffolded yet.
